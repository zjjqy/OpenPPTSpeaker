OpenPPTSpeaker

开源 PPT 讲演助手 · OpenPPTSpeaker（AI 语音讲解 + 可打断问答 + 手机遥控）

把 PDF / 图片转成可讲的演示，用语音逐页讲解、实时字幕、随时打断问答；手机扫码变无线遥控， 讲解声音与画面同屏、进度可控。本项目为开源 UI 重构原型：浅/深双主题 + 强调色可换， 已去除全部公司 / 行业相关品牌内容。

命名说明

· Speaker：既能主动讲演，也能被提问、可打断，是"会说话的演示"

主题与强调色

右上角可随时全局切换：浅 / 深 / 跟随 + 6 档强调色（存于 localStorage，各页联动）
中性底 / 语义色板（实时读取）
强调色档位
强调色用于状态光、主按钮、进度与语音能量，中性色承载信息层级。
