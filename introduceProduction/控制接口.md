# PPT HTML · OpenPPTSpeaker 控制接口规范

生成 / 改造 PPT 的 `index.html` 时，请遵循本规范。满足规范后，助手即可实现
**翻页与讲解内容精确同步**（无需改动主程序）。

## 一、必需：页面结构

```html
<div id="deck">
  <div class="slide active" data-title="第1页标题" name="slide">…</div>
  <div class="slide" data-title="第2页标题" name="slide">…</div>
  <!-- 每页一个 .slide，物理顺序 = 演讲稿.json 中 slides 数组顺序 -->
</div>
```

- 容器 `id="deck"`，每页一个 `.slide` 子元素，带 `data-title`（目录 / 日志用）。
- **物理顺序必须与 `演讲稿.json` 的 `slides` 数组一一对应**（第 N 个 `.slide` ↔ slides[N-1]）。
- 当前页通过 `.active` 类控制显示：`.slide { display:none } .slide.active { display:block }`。

## 二、必需：标准控制接口 `window.speakerDeck`

在页面 `<script>` 中暴露（**页码 1 起**，1 = 第一页）：

| 方法 | 说明 | 返回值 |
|---|---|---|
| `speakerDeck.goTo(page)` | 跳到第 page 页 | `true` 成功 / `false` 页码越界或非法 |
| `speakerDeck.next()` | 下一页 | 无要求 |
| `speakerDeck.prev()` | 上一页 | 无要求 |
| `speakerDeck.current()` | 当前页码（1 起） | number |
| `speakerDeck.count()` | 总页数 | number |

**关键要求：`goTo` 必须调用页面自身的翻页函数**（与键盘 / 按钮翻页同一条逻辑），
保证内部页码计数、`.active` 类、进度条、页码显示等全部同步。
切勿只切 CSS 类而不更新内部状态——否则外部翻页后，页面自身翻页会从旧位置继续，造成错位。

参考实现（直接可用）：

```html
<script>
(function () {
  var slides = Array.prototype.slice.call(document.getElementById('deck').querySelectorAll('.slide'));
  var total = slides.length;
  var current = 0; // 内部 0 起

  function render() {
    for (var i = 0; i < slides.length; i++) slides[i].classList.toggle('active', i === current);
    // …更新进度条/页码显示…
  }
  function goTo(i) {
    if (i < 0) i = 0;
    if (i > total - 1) i = total - 1;
    current = i; render();
  }

  window.speakerDeck = {
    goTo: function (page) {
      var i = Math.round(Number(page)) - 1;
      if (isNaN(i) || i < 0 || i > total - 1) return false;
      goTo(i);
      return true;
    },
    next: function () { goTo(current + 1); },
    prev: function () { goTo(current - 1); },
    current: function () { return current + 1; },
    count: function () { return total; }
  };

  render();
})();
</script>
```

## 三、可选：逐句聚光灯定位

若希望讲解到某一句时页面聚光灯聚焦对应内容，给对应元素加 `id`，
并在 `演讲稿.json` 该句的 `highlightId` 字段填同一 id：

- id 命名：`sp{页码}_{序号}`（文本元素）或 `sg{页码}_{序号}`（容器 / 分组），如 `sp5_2`。
- 无 `highlightId` 的句不聚焦，不影响翻页同步。

## 四、可选：坐标聚光 `window.speakerSpotlight`

导入的 PDF / 图片演示没有 DOM 元素可定位，此时用百分比坐标聚光：

```js
window.speakerSpotlight = function (rect) {
  // rect = { x, y, w, h }（0~100，相对页面）；null 表示清除
  return true
}
```

讲稿中每句可携带 `spotlight: { x, y, w, h }`，讲解到该句时自动调用。

## 五、降级兼容（不满足规范时的行为）

主程序按以下顺序降级尝试翻页，越靠前越可靠：

1. `window.speakerDeck.goTo(n)` —— 本规范接口
2. `window.huashunDeck.goTo(n)` —— 旧品牌接口名（历史演示页兼容）
3. `window.PPT.goTo(n-1)` —— 更旧接口（0 起索引）
4. 点击 `#tocList li[data-idx]` 目录项 —— 更老结构
5. 直接操作 `#deck .slide` 的 active 类 —— 兜底（**页面内部计数不同步**，仅保底显示）
